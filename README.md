# Open CapIQ Workbench

A single-page, zero-dependency web app that does two things. It maps the open-source alternatives to S&P Capital IQ (OpenBB, SEC EDGAR, FinanceToolkit, FinanceDatabase, yfinance), including what you give up by leaving a paid terminal. It also lets you run the core MBA valuation techniques live in the browser: DCF with a sensitivity table, CAPM/WACC, DuPont analysis, trading comps, and NPV/IRR/payback.

Open `index.html` locally, or use the GitHub Pages link in the repo description. There is no build step.

Educational use only, not investment advice. Peer data in the comps tab is fictional placeholder data.
